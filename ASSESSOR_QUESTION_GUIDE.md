# Complete Assessor Question Reference Guide

> **Protocol Version:** 2.1 (Assessment Protocol v2, Final)  
> **Purpose:** This reference handbook contains **all questions, passages, stimuli, and expected answers** for assessors administering the Dyslexia Assessment across all age groups (`5–7`, `8–10`, `11–13`, `14–15`) and sessions (`Session 1` & `Session 2`).

---

## 📌 Standard Assessor Spoken Scripts

Read the following instructions aloud to the child for each module:

| Module | Spoken Script / Assessor Prompt |
|---|---|
| **Handwriting Intro** | *"I am going to give you a few writing activities. Please do them as naturally as you can."* |
| **Copying** | *"Please copy this exactly as it is written. Take your time and try to write normally."* |
| **Dictation** | *"I will read a sentence. Please write what I say."* *(Note: Assessor may re-read sentence as many times as needed)* |
| **Reading** | *"Please read this passage aloud. Try to read it naturally."* |
| **RAN (Rapid Naming)** | *"Look at the items and name them from left to right as quickly and accurately as you can."* *(Followed by: "Ready? Go.")* |
| **Memory – Session 1 (Forward)** | *"I will say some numbers. Say them back to me in the same order."* |
| **Memory – Session 2 (Backward)** | *"I will say some numbers. Say them back to me in reverse order."* |

---

## 📋 Assessment Structure Overview

| Age Group | Session 1 Modules | Session 2 Modules |
|---|---|---|
| **5–7** | Handwriting, Reading, Phonological Awareness, RAN (5×3), Memory (Forward) | Handwriting, Reading, Grapheme–Phoneme Knowledge, Phonological Awareness, RAN (5×5), Memory (Backward) |
| **8–10** | Handwriting, Reading, Phonological Awareness, RAN (5×3), Memory (Forward) | Handwriting, Reading, Phonological Awareness, RAN (5×5), Memory (Backward) |
| **11–13** | Handwriting, Reading, Phonological Awareness, RAN (5×5), Memory (Forward) | Handwriting, Reading, Phonological Awareness, RAN (5×5), Memory (Backward) |
| **14–15** | Handwriting, Reading, Phonological Awareness, RAN (5×5), Memory (Forward) | Handwriting, Reading, Phonological Awareness, RAN (5×5), Memory (Backward) |

# 1. Age Group 5–7

---

### Age 5–7 : Session 1 (`S01`)

#### 1. Handwriting
- **Copying (`HW_5-7_S01_COPY`)**: Displayed on screen for child to copy:
  > *"The little bird sat on a tree."*
- **Dictation (`HW_5-7_S01_DICT`)** *(Assessor Only)*: Read aloud to child:
  > *"The boy has a red ball."*

#### 2. Reading (`R_5-7_S01`)
- **Title (Assessor view only):** *The Little Cat*
- **Passage shown to child (Audio recorded):**
  > *"Mia has a little cat. The cat is white and soft. It likes to play with a red ball."*

#### 3. Phonological Awareness
*(Marked as CORRECT / INCORRECT / NOT ATTEMPTED)*

- **Section: Rhyme Recognition**
  - **Q1 (Multiple Choice):** *"Which word rhymes with cat?"*  
    - Options: A: Sun | B: Hat | C: Dog | D: Pen  
    - **Expected Answer:** `Hat`
  - **Q2 (Multiple Choice):** *"Which word rhymes with cake?"*  
    - Options: A: Ball | B: Make | C: Fish | D: Run  
    - **Expected Answer:** `Make`

- **Section: Beginning Sound**
  - **Q3 (Multiple Choice):** *"Which word starts with the same sound as ball?"*  
    - Options: A: Boy | B: Cat | C: Sun | D: Fish  
    - **Expected Answer:** `Boy`
  - **Q4 (Open):** *"What is the first sound in sun?"*  
    - **Expected Answer:** `/s/`

- **Section: Sound Blending**
  - **Q5 (Open):** *"Say: /c/ + /a/ + /t/"*  
    - **Expected Answer:** `cat`
  - **Q6 (Open):** *"Say: /d/ + /o/ + /g/"*  
    - **Expected Answer:** `dog`

- **Section: Phoneme Identification**
  - **Q7 (Open):** *"What is the last sound in map?"*  
    - **Expected Answer:** `/p/`
  - **Q8 (Open):** *"What sound do fish and fan have at the beginning?"*  
    - **Expected Answer:** `/f/`

#### 4. Rapid Automatized Naming (RAN)
- **Grid ID:** `RAN_5-7_S01_OBJECTS_5x3_V2` (3 rows × 5 cols = 15 items)
- **Items:**
  | Row 1 | ⚽ ball | 🍎 apple | 🐶 dog | 🐱 cat | ☀️ sun |
  |---|---|---|---|---|---|
  | **Row 2** | 🐶 dog | 🐱 cat | ☀️ sun | 🍎 apple | ⚽ ball |
  | **Row 3** | 🍎 apple | ☀️ sun | ⚽ ball | 🐶 dog | 🐱 cat |

#### 5. Memory (Digit Recall – Forward)
*(Condition: FORWARD – "Say them back to me in the same order")*
- **Level 1 (2 digits):**
  - Trial 1: `4 - 7`
  - Trial 2: `2 - 8`
  - Trial 3: `5 - 1`
- **Level 2 (3 digits):**
  - Trial 1: `3 - 6 - 2`
  - Trial 2: `7 - 4 - 9`
  - Trial 3: `5 - 2 - 8`
- **Level 3 (4 digits):**
  - Trial 1: `4 - 1 - 7 - 3`
  - Trial 2: `8 - 2 - 5 - 9`

- **Section: Rhyming**  
  *Assessor prompt: "Ask: Does cat rhyme with hat?"*

  *Assessor prompt: "Ask: What is the first sound in...?"*

  - **Item 2:** `ball` ➔ **Expected:** `/b/`
  - **Item 3:** `fish` ➔ **Expected:** `/f/`
  - **Item 4:** `moon` ➔ **Expected:** `/m/`
  - **Item 5:** `dog` ➔ **Expected:** `/d/`

- **Section: Final Sound**  
  *Assessor prompt: "Ask: What is the last sound in...?"*
  - **Item 1:** `cat` ➔ **Expected:** `/t/`
  - **Item 2:** `sun` ➔ **Expected:** `/n/`
  - **Item 3:** `dog` ➔ **Expected:** `/g/`
  - **Item 4:** `map` ➔ **Expected:** `/p/`
  - **Item 5:** `fish` ➔ **Expected:** `/ʃ/`

#### 5. Rapid Automatized Naming (RAN)
- **Grid ID:** `RAN_5-7_S02_OBJECTS_5x5_V2` (5 rows × 5 cols = 25 items)
- **Items:**
  | Row 1 | ⚽ ball | 🍎 apple | ☀️ sun | 🐶 dog | 🐱 cat |
  |---|---|---|---|---|---|
  | **Row 2** | ☀️ sun | 🐱 cat | ⚽ ball | 🍎 apple | 🐶 dog |
  | **Row 3** | 🐱 cat | ☀️ sun | 🐶 dog | ⚽ ball | 🍎 apple |
  | **Row 4** | 🐶 dog | ⚽ ball | 🍎 apple | 🐱 cat | ☀️ sun |
  | **Row 5** | 🍎 apple | 🐶 dog | 🐱 cat | ☀️ sun | ⚽ ball |

#### 6. Memory (Digit Recall – Backward)
*(Condition: BACKWARD – "Say them back to me in reverse order")*
- Same sequence levels as S01:
  - **Level 1 (2 digits):** `[4, 7]`, `[2, 8]`, `[5, 1]`

## 📌 Scoring & Assessment Rules Summary

1. **Raw Data Collection Only:**
   - No diagnostic formulas, WPM, accuracy percentages, or totals are computed by the application.
2. **Audio-Recorded Modules:**
   - **Reading**, **RAN**, and **Memory** are recorded via audio for retrospective research analysis.
3. **Assessor-Scored Modules (Phonological Awareness & Grapheme–Phoneme):**
   - Each item is manually scored: `CORRECT (1)`, `INCORRECT (0)`, or `NOT ATTEMPTED (null)`.
   - Where the protocol does not specify an expected answer (e.g. 11–13 S02 complex segmentation), the assessor evaluates child response live.
4. **Handwriting:**
   - Timer tracking only for copying and dictation; physical paper sheets are retained and photographed separately.
